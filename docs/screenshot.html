短信通知转发

把手机收到的短信和指定 App 的通知，转发到你自己的企业微信、钉钉、飞书群，或自建服务。验证码在日志里自动打码，只连接你填的 Webhook。

怎么用

  1. 安装后按首页提示逐项授权：短信、通知使用权、忽略电池优化
  2. 在「通道」页添加机器人 Webhook，点「测试发送」确认能收到
  3. 在「规则」页按号码、关键词或正则筛选，不设规则则转发全部短信
  4. 在「日志」页查看每次转发的结果，失败会自动重试 3 次
